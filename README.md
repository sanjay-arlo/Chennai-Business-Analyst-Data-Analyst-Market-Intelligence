# Chennai Business Analyst & Data Analyst Market Intelligence

Portfolio project focused on Chennai BA/DA hiring patterns, salary ranges, skills, hiring hubs, industries, and work arrangements.

> **Important:** The included dataset is synthetic/illustrative and is intended for portfolio demonstration, not as live scraped job-market data.

## Project Files
- `index.html` — interactive Plotly dashboard
- `sample_listings_chennai.csv` — illustrative Chennai job listings
- `analysis_chennai.ipynb` — analysis notebook
- `requirements_chennai.txt` — Python dependencies

## Analysis Areas
- Salary by role
- Skill demand
- Chennai hiring hubs
- Work arrangement mix
- Industry mix
- BA vs DA skill profile
- Salary distribution
- Business recommendations
